# 2. Train Word Embeddings

This demo trains domain-specific embeddings from `corpus.txt` using cntext. The examples use Chinese text processing with `lang="chinese"`.

The target configuration for the paper demo is:

- GloVe: 200 dimensions, window size 15, 20 training iterations.
- Word2Vec: also trained for comparison.
- Evaluation: evaluate the trained GloVe model with cntext's built-in similarity evaluation.
- Loading: use `ct.load_w2v` to reload the saved model.
- Inspection: query nearest neighbors for selected Chinese words.

## Input

This step expects the corpus created in Step 1:

```text
WEPA-DEMO/outputs/corpus.txt
```

Each line should contain one cleaned Chinese document.

## Train a GloVe Model

```python
import cntext as ct

corpus_file = "WEPA-DEMO/outputs/corpus.txt"

glove_wv = ct.GloVe(
    corpus_file=corpus_file,
    lang="chinese",
    vector_size=200,
    window_size=15,
    max_iter=20,
    min_count=5,
    only_binary=True,
)
```

Expected saved model path:

```text
output/corpus-GloVe.200.15.bin
```

Notes:

- `vector_size=200` sets a 200-dimensional embedding space.
- `window_size=15` uses a relatively broad context window.
- `max_iter=20` sets 20 GloVe training iterations.
- `min_count=5` drops rare tokens. For very small demo corpora, reduce this value to `1` or `2`, but report that choice.
- cntext writes model files to the repository-level `output/` folder.

## Train a Word2Vec Model

Train Word2Vec on the same corpus for comparison.

```python
w2v_wv = ct.Word2Vec(
    corpus_file=corpus_file,
    lang="chinese",
    vector_size=200,
    window_size=15,
    max_iter=20,
    min_count=5,
    only_binary=True,
)
```

Expected saved model path:

```text
output/corpus-Word2Vec.200.15.bin
```

## Evaluate the GloVe Model

Use cntext's built-in similarity evaluation. This gives a lightweight diagnostic, not a full validation of WEPA measurement quality.

```python
ct.evaluate_similarity(glove_wv)
```

You can also reload the saved GloVe model first:

```python
glove_path = "output/corpus-GloVe.200.15.bin"
glove_wv = ct.load_w2v(glove_path)

ct.evaluate_similarity(glove_wv)
```

Interpretation:

- A similarity benchmark is a general embedding diagnostic.
- It does not validate a psychological construct by itself.
- WEPA still requires theory-driven anchors, expert review, and empirical validation.

## Load a Saved Embedding Model

Use `ct.load_w2v` to reload a saved model.

```python
glove_wv = ct.load_w2v("output/corpus-GloVe.200.15.bin")
w2v_wv = ct.load_w2v("output/corpus-Word2Vec.200.15.bin")
```

## Query Nearest Neighbors

Inspect nearest neighbors for words that matter in the research domain.

```python
# "目标" means "goal".
glove_wv.most_similar("目标", topn=10)

# "坚持" means "persistence" or "to persist".
glove_wv.most_similar("坚持", topn=10)

# "训练" means "training".
glove_wv.most_similar("训练", topn=10)
```

Example output shape:

```python
[("计划", 0.72), ("任务", 0.69), ("打卡", 0.66)]
```

Translations:

- `计划` means "plan".
- `任务` means "task".
- `打卡` means "check in" or "log an activity".

## Coverage Check for WEPA Anchors

Before using anchors, check whether they are in the embedding vocabulary.

```python
positive_pole = ["坚持", "努力", "完成"]  # persist, strive, complete
negative_pole = ["放弃", "拖延", "逃避"]  # give up, delay, avoid

for word in positive_pole + negative_pole:
    print(word, word in glove_wv)
```

If an anchor is missing:

- check tokenization,
- inspect corpus frequency,
- consider a theory-consistent alternative,
- document the change.
