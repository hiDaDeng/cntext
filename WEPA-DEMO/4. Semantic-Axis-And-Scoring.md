# 3. Semantic-Axis and WEPA Scoring

This demo shows how to construct a semantic axis, score Chinese texts with `project_text`, and use the compact one-line `ct.wepa` function.

The examples use `lang="chinese"` and Chinese anchor words. English translations are included in comments.

## Load the Embedding Model

Use the GloVe model trained in Step 2.

```python
import cntext as ct
import pandas as pd

wv = ct.load_w2v("output/corpus-GloVe.200.15.bin")
```

## Define Anchor Words

The example construct is goal commitment. The anchors below are illustrative only. For empirical research, anchors should be developed from theory, reviewed by domain experts, and validated empirically.

```python
positive_pole = [
    "坚持",  # persist
    "努力",  # strive
    "完成",  # complete
    "目标",  # goal
    "打卡",  # check in / log an activity
]

negative_pole = [
    "放弃",  # give up
    "拖延",  # delay / procrastinate
    "逃避",  # avoid
    "懈怠",  # slack off
    "中断",  # interrupt / discontinue
]
```

## Check Anchor Coverage

```python
anchor_check = pd.DataFrame(
    {
        "anchor": positive_pole + negative_pole,
        "pole": ["positive"] * len(positive_pole) + ["negative"] * len(negative_pole),
        "in_vocab": [word in wv for word in positive_pole + negative_pole],
    }
)

print(anchor_check)
```

If important anchors are out of vocabulary, review tokenization and corpus frequency. Do not silently replace anchors without documenting the reason.

## Construct the Semantic Axis

Use cntext's built-in semantic-axis function.

```python
goal_commitment_axis = ct.generate_concept_axis(
    wv=wv,
    poswords=positive_pole,
    negwords=negative_pole,
)

print(goal_commitment_axis.shape)
```

Interpretation:

- The axis points from the negative pole toward the positive pole.
- In this example, higher scores indicate stronger linguistic salience of goal commitment.
- Scores are relative to the embedding model and anchor choices.

## Score One Text with `project_text`

```python
text = "今天完成了5公里跑步，坚持训练很有成就感。"
# Translation: "I completed a 5 km run today and feel accomplished for keeping up with training."

score = ct.project_text(
    wv=wv,
    text=text,
    axis=goal_commitment_axis,
    lang="chinese",
)

print(score)
```

## Score One Text with One-Line `ct.wepa`

The compact WEPA function constructs the semantic axis and scores the text in one call.

```python
score = ct.wepa(
    wv=wv,
    text="今天完成了5公里跑步，坚持训练很有成就感。",
    poswords=positive_pole,
    negwords=negative_pole,
    lang="chinese",
)

print(score)
```

This is equivalent to:

```python
axis = ct.generate_concept_axis(wv, positive_pole, negative_pole)
score = ct.project_text(wv, "今天完成了5公里跑步，坚持训练很有成就感。", axis, lang="chinese")
```

## Score Multiple Texts

```python
texts = [
    "今天完成了5公里跑步，坚持训练很有成就感。",
    # Translation: "I completed a 5 km run today and feel accomplished for keeping up with training."

    "最近有点累，但还是想继续打卡。",
    # Translation: "I have been a little tired recently, but I still want to keep checking in."

    "目标还没有完成，明天继续努力。",
    # Translation: "The goal is not finished yet; I will keep trying tomorrow."

    "这周一直拖延训练，差点想放弃。",
    # Translation: "I kept delaying training this week and almost wanted to give up."
]

rows = []
for text in texts:
    rows.append(
        {
            "text": text,
            "wepa_score": ct.wepa(
                wv=wv,
                text=text,
                poswords=positive_pole,
                negwords=negative_pole,
                lang="chinese",
            ),
        }
    )

score_df = pd.DataFrame(rows)
print(score_df.sort_values("wepa_score", ascending=False))
```

## Score the Merged CSV from Step 1

```python
df = pd.read_csv("WEPA-DEMO/outputs/all_texts.csv")

df["goal_commitment_wepa"] = df["clean_text"].map(
    lambda text: ct.wepa(
        wv=wv,

    )

df.to_csv(
    "WEPA-DEMO/outputs/all_texts_with_wepa_scores.csv",

)
```

## Interpretation

WEPA scores should be interpreted as construct-related linguistic salience in text. In this example, a higher score means that the text is more semantically aligned with the positive pole of goal commitment than with the negative pole.

Do not interpret scores as:

- direct observations of latent psychological states,
- clinical diagnoses,
- causal effects,
- universal indicators across platforms,
- evidence of strict measurement invariance.

## Practical Checks

Before using WEPA scores in analysis:

```python
print(df["goal_commitment_wepa"].describe())
print(df[["clean_text", "goal_commitment_wepa"]].sort_values("goal_commitment_wepa").head())
print(df[["clean_text", "goal_commitment_wepa"]].sort_values("goal_commitment_wepa").tail())
```

Recommended checks:

- Inspect high-scoring and low-scoring examples.
- Check vocabulary coverage.
- Review anchor words with domain experts.
- Test measurement stability across time windows if making longitudinal comparability claims.
- Report corpus, embeddings, anchors, preprocessing, and validation steps.
